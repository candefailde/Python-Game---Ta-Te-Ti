# 🎮 Ta-Te-Ti en Python

Proyecto clásico de Ta-Te-Ti desarrollado en Python como práctica de lógica, estructuras de control y programación modular.

---

## 🚀 Funcionalidades

- Juego por turnos (X y O)
- Validación de entradas del usuario
- Control de posiciones ocupadas
- Detección automática de ganador
- Detección de empate
- Interfaz de consola simple

---

## 🧠 Aprendizajes

- Manejo de listas
- Estructuras de control (while, if)
- Funciones
- Validación de input del usuario
- Lógica de juegos por turnos

---
